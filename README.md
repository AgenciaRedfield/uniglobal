## 🛠 Tecnologias Utilizadas

* **HTML5 Semântico**: Estrutura da página.
* **CSS3 Customizado**: Estilos de sobreposição (overlay), gradientes e animações.
* **Bootstrap 5**: Grid system, componentes (Carousel, Cards, Modal) e responsividade.
* **Bootstrap Icons**: Ícones vetoriais para UI.

## ✨ Funcionalidades

* **Header Hero Imersivo**: Imagem de fundo com filtro gradiente azul e botões de Call-to-Action (CTA).
* **Carrossel de Depoimentos**: Slider responsivo para exibir feedbacks de alunos (imagens estáticas).
* **Botão Flutuante (WhatsApp)**: Ícone fixo no canto inferior direito com mensagem pré-configurada para conversão rápida.
* **Rodapé Estruturado**: Layout de 4 colunas incluindo seção dedicada a **Parceiros** (Uni Global, IDS, IGS, Ingedesa).
* **Responsividade Total**: Adaptável para Celulares, Tablets e Desktops.
